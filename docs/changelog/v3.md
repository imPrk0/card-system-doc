# V3 版本更新日志 {#title}


## 3.20 (2026-10-22) <Badge type="danger" text="紧急" /> {#3-20}

::: danger 重要

此次更新主要是解决 [PHP 严重漏洞 PHP2Shell 修复通知](/notice/2026/10/critical-vulnerabilities-in-php-php2shell) 漏洞，务必更新修复！

:::

[V3.20](https://github.com/Tai7sy/card-system/releases/tag/3.20) 文件下载地址：

```
https://github.com/Tai7sy/card-system/releases/download/3.20/card_release.tar.gz
```

- 将 Laravel 框架升级至 12 版本
- 将 PHP 版本随框架升级至 8.2 及以上版本

安装完成更新后，需要手动切换 PHP CLI 版本与网站 PHP 版本，随后到终端命令行确定 PHP CLI 执行版本是否符合预期：
```bash
$ php --version
```

> PHP <font color="red"><b>8.4.27</b></font> (cli) (built: Oct 21 2026 10:00:00) ( NTS )<br />
> Copyright (c) The PHP Group

确定执行版本后在网站目录执行 `php artisan up` 命令。

```bash {2}
$ cd /www/wwwroot/example.com #进入网站目录
$ php artisan up
```
